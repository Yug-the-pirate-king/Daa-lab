1. BINARY SEARCH ALGORITHM
--------------------------
* Algorithm:
  1. Initialize low = 0 and high = n - 1.
  2. While low <= high:
     a. Calculate mid = low + (high - low) / 2.
     b. If array[mid] == target, return mid.
     c. If array[mid] < target, set low = mid + 1.
     d. Else, set high = mid - 1.
  3. If the loop terminates without finding the target, return -1 (Not found).
* Complexity:
  - Time Complexity: Best Case: O(1) | Average & Worst Case: O(log n)
  - Space Complexity: O(1) (Iterative approach)

2. FINDING MIN AND MAX (DIVIDE AND CONQUER)
-------------------------------------------
* Algorithm:
  1. If the array has only one element, return it as both min and max.
  2. If the array has two elements, compare them and return the min and max.
  3. Otherwise, divide the array into two halves at the middle index.
  4. Recursively find the min and max of the left half and the right half.
  5. Return the absolute minimum of the two mins and maximum of the two maxes.
* Complexity:
  - Time Complexity: O(n) (Performs roughly 3n/2 - 2 comparisons)
  - Space Complexity: O(log n) (For the recursive call stack)

3. MERGE SORT ALGORITHM
-----------------------
* Algorithm:
  1. Divide: Find the middle point to divide the array into two halves.
  2. Conquer: Recursively call Merge Sort for the left half.
  3. Conquer: Recursively call Merge Sort for the right half.
  4. Combine: Merge the two sorted halves back into a single sorted array.
* Complexity:
  - Time Complexity: Best, Average, and Worst Case: O(n log n)
  - Space Complexity: O(n) (For the auxiliary temporary arrays)

4. QUICK SORT ALGORITHM
-----------------------
* Algorithm:
  1. Choose a pivot element (commonly the last element in the array).
  2. Partition the array such that all elements smaller than the pivot are placed to its left, and all larger elements to its right.
  3. Recursively apply Quick Sort to the left sub-array (elements before pivot).
  4. Recursively apply Quick Sort to the right sub-array (elements after pivot).
* Complexity:
  - Time Complexity: Best & Average Case: O(n log n) | Worst Case: O(n^2) (When array is already sorted)
  - Space Complexity: O(log n) (For the recursive call stack)

5. SELECTION SORT ALGORITHM
---------------------------
* Algorithm:
  1. Iterate through the array from index i = 0 to n-1.
  2. Find the minimum element in the unsorted portion of the array (from i to n-1).
  3. Swap the found minimum element with the element at index i.
  4. Repeat this process until the entire array is sorted.
* Complexity:
  - Time Complexity: Best, Average, and Worst Case: O(n^2)
  - Space Complexity: O(1) (In-place algorithm)

6. JOB SEQUENCING WITH DEADLINES (GREEDY)
-----------------------------------------
* Algorithm:
  1. Sort all jobs in descending order of their profit.
  2. Find the maximum deadline among all jobs to determine the maximum time slots available.
  3. Initialize an array of time slots as empty (or false).
  4. Iterate through the sorted jobs:
     a. For each job, search for an empty time slot from its deadline down to 1.
     b. If an empty slot is found, assign the job to this slot and add its profit to the total.
  5. Return the sequence of jobs and total maximum profit.
* Complexity:
  - Time Complexity: O(n^2) (Due to nested loops searching for a free slot)
  - Space Complexity: O(n) (To track scheduled jobs and slots)

7. MINIMUM SPANNING TREE - PRIM'S ALGORITHM
-------------------------------------------
* Algorithm:
  1. Create a boolean array mstSet[] to track vertices included in the MST.
  2. Initialize key values of all vertices to infinity, except the starting vertex which is set to 0.
  3. While the MST doesn't contain all vertices:
     a. Pick a vertex u not in mstSet with the minimum key value.
     b. Include u in mstSet.
     c. Update the key values of all adjacent unvisited vertices of u. If edge weight u-v is less than the current key value of v, update it.
* Complexity:
  - Time Complexity: O(V^2) with Adjacency Matrix | O(E log V) with Adjacency List + Min-Heap
  - Space Complexity: O(V) (To store keys, parents, and MST tracking set)

8. MINIMUM SPANNING TREE - KRUSKAL'S ALGORITHM
----------------------------------------------
* Algorithm:
  1. Sort all edges in the graph in non-decreasing order of their weight.
  2. Initialize a disjoint set (Union-Find) to keep track of cycles.
  3. Iterate through the sorted edges:
     a. Pick the smallest edge. Check if including it forms a cycle using the disjoint set.
     b. If it doesn't form a cycle, include it in the MST and perform Union on the sets.
     c. If it forms a cycle, discard it.
  4. Repeat until there are V-1 edges in the MST.
* Complexity:
  - Time Complexity: O(E log E) or O(E log V) (Dominating factor is sorting the edges)
  - Space Complexity: O(V + E) (To store the edges and Disjoint Set arrays)

9. SINGLE SOURCE SHORTEST PATH - DIJKSTRA'S ALGORITHM
-----------------------------------------------------
* Algorithm:
  1. Initialize distances of all vertices to infinity, and the source vertex distance to 0.
  2. Create a set (sptSet) to keep track of vertices whose shortest distance is finalized.
  3. While sptSet doesn't include all vertices:
     a. Pick an unvisited vertex u with the minimum distance value.
     b. Add u to sptSet.
     c. For all adjacent unvisited vertices v of u, relax the edge:
        If dist[u] + weight(u, v) < dist[v], then update dist[v] = dist[u] + weight(u, v).
* Complexity:
  - Time Complexity: O(V^2) with Adjacency Matrix | O(E log V) with Min-Heap
  - Space Complexity: O(V) (To store distance and visited states)

10. ALL PAIRS SHORTEST PATH - FLOYD-WARSHALL ALGORITHM
------------------------------------------------------
* Algorithm:
  1. Initialize the solution distance matrix dist[][] identically to the input graph's adjacency matrix.
  2. Use three nested loops with indices k, i, and j:
     - k represents the intermediate vertex.
     - i represents the source vertex.
     - j represents the destination vertex.
  3. For every pair (i, j), update the shortest path using k:
     If dist[i][j] > dist[i][k] + dist[k][j], then update dist[i][j] = dist[i][k] + dist[k][j].
* Complexity:
  - Time Complexity: O(V^3)
  - Space Complexity: O(V^2) (For the 2D distance matrix)

11. TREE TRAVERSALS (INORDER, PREORDER, POSTORDER)
--------------------------------------------------
* Preorder Traversal (Root, Left, Right):
  1. Visit the root node.
  2. Recursively traverse the left subtree.
  3. Recursively traverse the right subtree.

* Inorder Traversal (Left, Root, Right):
  1. Recursively traverse the left subtree.
  2. Visit the root node.
  3. Recursively traverse the right subtree.

* Postorder Traversal (Left, Right, Root):
  1. Recursively traverse the left subtree.
  2. Recursively traverse the right subtree.
  3. Visit the root node.
* Complexity:
  - Time Complexity: O(N) (Every node is visited exactly once)
  - Space Complexity: O(H) (Where H is tree height, representing recursion depth)

12. GRAPH TRAVERSALS (BFS & DFS)
--------------------------------
* Breadth-First Search (BFS):
  1. Initialize an empty queue and a boolean array to keep track of visited vertices.
  2. Mark the starting vertex as visited and enqueue it.
  3. While the queue is not empty:
     a. Dequeue a vertex from the queue and process (print) it.
     b. Get all adjacent vertices of the dequeued vertex. If an adjacent vertex has not been visited, mark it visited and enqueue it.

* Depth-First Search (DFS):
  1. Initialize a boolean array to keep track of visited vertices.
  2. Start at a given vertex, mark it as visited, and process (print) it.
  3. Recursively call the DFS function for all unvisited adjacent vertices of the current vertex.
* Complexity:
  - Time Complexity: O(V + E) (For both BFS and DFS when using an Adjacency List)
  - Space Complexity: O(V) (Queue / Recursion stack sizes scale with number of vertices)
